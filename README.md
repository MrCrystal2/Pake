# Aplikacja Pake

## Krok 1: Uruchomienie Builda (Template formularza)

W lewej kolumnie kliknij Build App with Pake CLI, a potem po prawej Run workflow. Wypełnij dokładnie tak:

Pole Co wpisać Notes
App URL <adres> Pełny URL
App Name <Nazwa> Bez spacji
App Icon Empty Pobierze favicon
Platform MacOS-latest Dla maca
Show menu True Pasek menu górny
Show title bar True Zarządzanie oknem

Kliknij zielone Run workflow.

## Krok 2: Pobieranie i Instalacja

1. Czekaj na zielony znacznik (ok. 5-7 min).
2. Kliknij w nazwę zakończonego zadania (np. Build App with Pake CLI).
3. Przewiń na sam dół do sekcji Artifacts.
4. Kliknij w nazwę pliku (np. ChatGPT_macos.zip)
5. Na Macu: Rozpakuj ZIP, przeciągnij aplikację do folderu /Applications.

## Krok 3: Ominięcie blokady Apple

Przy pierwszym uruchomieniu

1. Kliknij na apkę prawym przyciskiem myszy.
2. Wybierz Otwórz.
3. Gdy wyskoczy okno ostrzeżenia, kliknij przycisk Otwórz (teraz będzie dostępny).
